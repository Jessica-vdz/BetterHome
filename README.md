# BetterHome

## About the Project

BetterHome is a project I worked on to gain more experience with web development and hardware integration. The goal of the project was to create a web application that combines software with physical hardware components.

The project includes a website with different pages and a dashboard, as well as hardware-related components such as lights and a DHT11 sensor.

I worked on different parts of the project, including the frontend and the integration of hardware components. This allowed me to gain more practical experience with web development and understand how software can interact with physical devices.

## Features

- **Dashboard:** A dashboard for the BetterHome application.
- **Hardware Integration:** Working with physical hardware components.
- **Light Components:** Hardware-related functionality for lights.
- **Sensor Integration:** Working with a DHT11 temperature and humidity sensor.
- **Web Interface:** A website with multiple pages and a user interface.

## Tech Stack

**Hardware**
- Esp32
- 3 Led's
- solar panels
- servo
- ldr

**Software**
- **HTML** — Structuring the website.
- **CSS** — Styling the frontend.
- **JavaScript** — Implementing interactive functionality.
- **Hardware:** Lights and a DHT11 sensor.
